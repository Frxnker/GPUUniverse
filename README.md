# 🌌 GPU Universe — Portal de Hardware Gráfico

[![Project Version](https://img.shields.io/badge/version-1.2.0-blueviolet)](https://github.com/Frxnker/gpu-universe)
[![Status](https://img.shields.io/badge/status-active-success)]()
[![License](https://img.shields.io/badge/license-MIT-green)]()

**GPU Universe** es una plataforma interactiva diseñada para entusiastas y profesionales del hardware. Ofrece una base de datos exhaustiva y visualmente impactante que abarca desde las tarjetas gráficas domésticas más icónicas hasta los aceleradores de IA y centros de datos más potentes del planeta.

![Preview](https://images.unsplash.com/photo-1591488320449-011701bb6704?auto=format&fit=crop&q=80&w=1000)

## ✨ Características Principales

- 🌍 **Internacionalización Completa**: Soporte nativo para 6 idiomas (Español, Inglés, Francés, Alemán, Italiano y Ruso) con cambio dinámico y detección automática.
- 🔍 **Buscador Inteligente**: Localiza cualquier GPU (Desktop, Laptop, Workstation o Server) con autocompletado y detalles técnicos instantáneos.
- ⚖️ **Comparador Dinámico**: Herramienta interactiva para comparar TFLOPS, VRAM y Ancho de Banda entre diferentes generaciones.
- 📱 **Diseño Ultra-Premium**: Estética *Glassmorphism* con efectos de partículas, fondos dinámicos y animaciones fluidas (60 FPS).
- 📈 **Base de Datos 2026**: Incluye las últimas generaciones como la serie **RTX 50 (Blackwell)** de NVIDIA, **RDNA 4** de AMD y **Battlemage** de Intel.
- 💹 **Conversión de Moneda**: Precios localizados automáticamente según el idioma (EUR, USD, RUB).

## 🚀 Tecnologías Utilizadas

- **Frontend**: HTML5 Semántico, CSS3 (Vanilla con variables y Grid/Flexbox).
- **Lógica**: JavaScript ES6+ (Vanilla, sin dependencias externas pesadas).
- **Diseño**: Tipografía *Outfit* y *JetBrains Mono* (vía Google Fonts), Iconografía moderna.
- **Rendimiento**: Carga ultra-ligera (<150KB en total), optimizada para SEO y velocidad.

## 📁 Estructura del Proyecto

```text
├── index.html          # Página principal y Timeline
├── gaming.html         # Sección de GPUs domésticas y portátiles
├── workstation.html    # Sección profesional (Quadro, RTX Pro, etc.)
├── server.html         # Sección Enterprise (H100, B200, MI300X)
├── compare.html        # Herramienta de comparación técnica
├── style.css           # Sistema de diseño y media queries
├── i18n.js             # Motor de traducción y diccionarios
├── data.js             # Base de datos centralizada de hardware
└── app.js              # Lógica de búsqueda, modales y animaciones
```

## 🛠️ Instalación y Uso

No requiere compilación ni servidores complejos. Puedes ejecutarlo localmente de forma inmediata:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Frxnker/gpu-universe.git
   ```
2. Abre `index.html` en cualquier navegador moderno.
3. (Opcional) Usa una extensión como *Live Server* en VS Code para la mejor experiencia de desarrollo.
